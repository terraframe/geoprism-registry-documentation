# Synchronize an External System

An external system synchronization enables the ability to push data from Geoprism Registry to another system. This functionality is designed to simplify the integration of systems by providing a simple user interface and enabling a catalog of synchronization profiles maintained in Geoprism Registry.&#x20;

#### Other ways to integrate with Geoprism Registry

While synchronizations enable pushing to external systems the _API_ and _Labeled Property Graph_ functionality provides access to system data and functionality for pulling data from Geoprism Registry.&#x20;
