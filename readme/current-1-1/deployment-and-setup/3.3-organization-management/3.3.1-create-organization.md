# 3.3.1. Create an organization

Organizations can only be created by users with the System Administrator role.

1.  Go to the **Settings** module.

    <figure><img src="../../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
2.  Scroll down to the **Organizations** section and click on the **+** icon.

    ![](<../../../../.gitbook/assets/image (10) (3).png>)
3.  Complete the **Organization** modal that opens up.<br>

    <figure><img src="../../../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

    <table data-header-hidden><thead><tr><th width="360"></th><th></th></tr></thead><tbody><tr><td><strong>Form field</strong></td><td><strong>Description</strong></td></tr><tr><td>Unique ID</td><td>Unique identifier of the organization.</td></tr><tr><td>Organization Name</td><td>Name of the organization in the default and any installed locales.</td></tr><tr><td>Contact Information</td><td>Details of the primary contact point of the organization in the default and any installed locales.</td></tr><tr><td>Enabled</td><td>Option to specify if an organization is enabled. Disabled organizations limit functionality for members of that organization.</td></tr></tbody></table>
4.  Click **Submit**. The organization now appears in the table under the **Organizations** section in the **Settings** module.

    ![](<../../../../.gitbook/assets/image (6).png>)
