# Access and Permissions

This section explains how people get into Geoprism Registry and how their access is managed.

* [logging-in.md](logging-in.md "mention") with a Geoprism Registry account or an external account.
* [User management](user-management/README.md): adding and inviting users, assigning their roles, and managing passwords.

What each user can see and do depends on their roles. See [User roles and rights](../geoprism-registry-key-components/user-roles-and-rights/README.md) for what each role can do.
