# User management

User accounts are managed from the **User Accounts** section of the **Settings** page. **Manage Accounts** opens the list of users, with their username, name, phone number, email address and status. System Administrators and Registry Administrators can add, invite and edit users there.

Each user's roles decide what they can do. Roles are assigned for an organization: a user can be a Registry Administrator for the organization, or have a role such as Registry Maintainer or Registry Contributor for each of its Geo-Object Types. See [User roles and rights](../../geoprism-registry-key-components/user-roles-and-rights/README.md).

* [adding-users.md](adding-users.md "mention"): create an account for someone.
* [inviting-users.md](inviting-users.md "mention"): email someone a link to create their own account.
* [resetting-password.md](resetting-password.md "mention"): reset your own forgotten password.
* [change-password.md](change-password.md "mention"): change another user's password.
