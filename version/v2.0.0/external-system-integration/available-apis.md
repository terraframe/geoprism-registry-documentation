# Available APIs

Geoprism Registry has a REST API that developers can use to read and work with registry data from other systems. It can also look up data using external system identifiers, so a system can find Geo-Objects by its own IDs.

See the [API documentation](https://api.geoprismregistry.com) for the available endpoints and how to use them.

To push data to another system instead, see [Register an External System](register-an-external-system/README.md) and [Synchronize an External System](synchronize-an-external-system/README.md).
