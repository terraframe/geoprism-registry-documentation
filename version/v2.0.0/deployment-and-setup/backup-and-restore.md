# Backup and restore

A System Administrator can back up, restore and delete the data of a Geoprism Registry instance from the **Backup and Restore** section of the **Settings** page.

## Backing up

1.  Go to the **Settings** page from the sidebar.

    ![](<../../../.gitbook/assets/image (28).png>)
2.  In the **Backup and Restore** section, click **Backup**. A ZIP file of the instance's data downloads to your computer.

## Restoring

1.  In the **Backup and Restore** section, click **Restore**.
2.  In **Restore instance data**, choose a backup ZIP file.
3.  Click **Submit**.

## Deleting instance data

{% hint style="danger" %}
This deletes all of the data in the instance and can't be undone. Back up the data first.
{% endhint %}

1.  In the **Backup and Restore** section, click **Delete instance data**.
2.  Confirm by clicking **Delete**.
