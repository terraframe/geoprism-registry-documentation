# Localization

Geoprism Registry's user interface can be translated into other languages. English is the default locale, and you can add others. Localization is managed by a System Administrator in the **Localization** section of the **Settings** page.

To add a language:

1.  [install-a-new-locale.md](install-a-new-locale.md "mention")
2.  [export-the-default-localization-spreadsheet.md](export-the-default-localization-spreadsheet.md "mention")
3.  [add-or-edit-a-locale-in-the-exported-spreadsheet.md](add-or-edit-a-locale-in-the-exported-spreadsheet.md "mention")
4.  [import-a-new-locale-from-the-spreadsheet.md](import-a-new-locale-from-the-spreadsheet.md "mention")

Once a locale is installed, users can [switch-locale.md](switch-locale.md "mention"). To remove a locale, see [uninstall-a-locale.md](uninstall-a-locale.md "mention").

The translations only cover the interface and the names of your types and hierarchies. Your data, such as Geo-Object names, is translated with the per-locale fields in each form and import.
