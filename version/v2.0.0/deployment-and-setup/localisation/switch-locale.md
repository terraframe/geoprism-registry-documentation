# Switch locale

Anyone can switch Geoprism Registry to any installed locale.

1.  Click the menu icon at the top right of the page. It only appears when at least one locale other than the default has been installed.

2.  Select the locale you want. The page refreshes and shows Geoprism Registry in that language, for all the text that has been translated.
