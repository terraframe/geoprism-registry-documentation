# Creating a new installation

Geoprism Registry is a Java web application that runs on Tomcat, and is installed with Docker. Read these pages before you install:

1.  [system-architecture.md](system-architecture.md "mention"): the components of an installation and how they fit together.
2.  [hardware-requirements.md](hardware-requirements.md "mention"): the server and software you'll need.
3.  [ssl.md](ssl.md "mention"): how to serve Geoprism Registry over HTTPS with a reverse proxy.
4.  [install-config-update.md](install-config-update.md "mention"): where to find the current installation, configuration and update instructions.
