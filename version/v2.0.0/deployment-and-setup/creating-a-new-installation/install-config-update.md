# Installation, configuration and update

Geoprism Registry is installed and updated with Docker. The most current instructions for installing, configuring and updating it are on [Docker Hub](https://hub.docker.com/r/terraframe/geoprism-registry).

The [example docker-compose.yml](https://github.com/terraframe/geoprism-registry/blob/master/src/build/docker/georegistry/docker-compose.yml) is a good starting point for a new installation. See [system-architecture.md](system-architecture.md "mention") for what it sets up.
