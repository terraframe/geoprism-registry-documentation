# Organization management

Geoprism Registry manages data across multiple organizations. Each Geo-Object Type, hierarchy and Business Type belongs to one organization, and only people with a role in that organization can maintain its data. Each organization is managed by its own Registry Administrators.

Organizations are managed by a System Administrator in the **Organizations** section of the **Settings** page.
