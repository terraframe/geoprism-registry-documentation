# Source Authorities

A **Source Authority** defines who is responsible for a piece of data and what type of organization they are, such as a government agency, a mapping agency or an NGO. Recording the Source Authority is a first step toward understanding how authoritative the data is.

Source Authorities are used in other parts of Geoprism Registry:

* A [Data Source](../data-sources/add-a-data-source.md) names the Source Authority that has authority over it.
* When you [import a spreadsheet](../../curate/import-geospatial-data/import-a-spreadsheet.md), you can map alternative ID columns in your file to a Source Authority.

See [add-a-source-authority.md](add-a-source-authority.md "mention") and [managing-an-existing-source-authority.md](managing-an-existing-source-authority.md "mention") for more detail.
