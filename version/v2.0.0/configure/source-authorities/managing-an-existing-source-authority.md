# Managing an Existing Source Authority

The **Source Authorities** page lists each Source Authority with its authority type and label. Each row has three icons:

<figure><img src="../../../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>

* **View** opens the Source Authority read-only.
* **Edit** opens the form so you can change any field except the code. Click **Submit** to save your changes. See [add-a-source-authority.md](add-a-source-authority.md "mention") for details of each field.
* **Delete** removes the Source Authority after you confirm by clicking **Delete**.

{% hint style="warning" %}
A Source Authority can't be deleted while a [Data Source](../data-sources/README.md) uses it. Change or delete those Data Sources first.
{% endhint %}
