# Data Sources

A **Data Source** describes where data in Geoprism Registry came from, such as a ministry database, a survey, a research project or an open dataset. It records the source's link, how the data is governed, the metadata standard it uses, and the [Source Authority](../source-authorities/README.md) responsible for it.

When you import data, you can choose the Data Source it came from. Geoprism Registry stores the Data Source with the imported values for the period of validity of the import, so users can see where each value came from. See [Import Geospatial Data](../../curate/import-geospatial-data/README.md), [Import Business Data](../../curate/import-business-data.md) and [Import Edge Data](../../curate/import-edge-data.md).
