# Geo-Object Type Groups

A **group** collects related Geo-Object Types that share a geometry type, visibility and attributes. For example, a Health Facility group could contain Hospital, Health Centre and Health Post Geo-Object Types.

Each Geo-Object Type in a group:

* Uses the group's geometry type and visibility.
* Has all the group's attributes, and can have attributes of its own.
* Uses the permissions of the group.

In a hierarchy, a group can only be a child. See [Hierarchies](../hierarchies/README.md).
