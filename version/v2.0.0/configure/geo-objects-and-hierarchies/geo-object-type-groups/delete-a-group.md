# Delete a group

{% hint style="info" %}
Registry Administrators can delete groups under the curation mandate of their organization
{% endhint %}

{% hint style="warning" %}
Deleting a group also deletes every Geo-Object Type in it. A group can't be deleted while it, or any Geo-Object Type in it, is part of a hierarchy.
{% endhint %}

1. Navigate to the **Geo-Objects and Hierarchies** page from the sidebar.
2. Click the three-dot menu next to the group and select **Delete**.

   <figure><img src="../../../../../.gitbook/assets/image (82).png" alt=""><figcaption></figcaption></figure>
3. A message asks you to confirm that you want to delete the group. Click **Delete**.
