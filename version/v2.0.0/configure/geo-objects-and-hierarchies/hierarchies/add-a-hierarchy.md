# Adding a hierarchy

{% hint style="info" %}
Registry Administrators can add a hierarchy for the organization they are a part of.
{% endhint %}

1. Navigate to the **Geo-Objects and Hierarchies** page from the sidebar and select **Hierarchies** at the top of the list.

   <figure><img src="../../../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
2. Click **Add Hierarchy** under your organization.

   <figure><img src="../../../../../.gitbook/assets/image (17) (1).png" alt=""><figcaption></figcaption></figure>
3. Fill out the form:

| Field | Description | Required |
| ----- | ----------- | -------- |
| Code | The unique human-readable identifier of the hierarchy. It can't be changed later. | Required |
| Label | The display label, with one field per installed locale. The default locale is required. | Required |
| Description (Abstract) | A description of the hierarchy, with one field per installed locale. | |
| Progress | A description of the progress so far in creating and curating the data for this hierarchy. | |
| Acknowledgement | Acknowledgements relevant to the hierarchy. | |
| Disclaimer | Any disclaimers relevant to the hierarchy. | |
| Access Constraints | Access constraints relevant to the hierarchy. | |
| Use Constraints | Use constraints relevant to the hierarchy. | |
| Organization | The organization the hierarchy belongs to. If you're a Registry Administrator for more than one organization, you can choose it. It can't be changed later. | |
| Contact name | The full name of the person responsible for managing this hierarchy. | |
| Telephone number | The telephone number of that person. | |
| Email address | The email address of that person. | |

The form has no save button. The hierarchy is saved when you close the form.

4. Click **Close**.

   <figure><img src="../../../../../.gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>
5. A message says **You have unsaved changes**. Click **Save changes and close**.

   <figure><img src="../../../../../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure>
6. Add Geo-Object Types to the hierarchy. See [manage-the-content-of-the-hierarchy.md](manage-the-content-of-the-hierarchy.md "mention").
