# Deleting a hierarchy

{% hint style="info" %}
Registry Administrators can delete hierarchies for the organization they are a part of.
{% endhint %}

{% hint style="warning" %}
Lists and spatial data that use the hierarchy are marked as invalid, and any hierarchy that inherits it stops inheriting. You don't need to remove the Geo-Object Types from the hierarchy first. A hierarchy that came from a different Geoprism Registry node can't be deleted.
{% endhint %}

1. Navigate to the **Geo-Objects and Hierarchies** page from the sidebar and select **Hierarchies** at the top of the list.

   <figure><img src="../../../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
2. Click the three-dot menu next to the hierarchy and select **Delete**.

   <figure><img src="../../../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure>
3. A message asks you to confirm that you want to delete the hierarchy. Click **Delete**.
