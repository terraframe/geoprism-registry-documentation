# Deleting a hierarchy

1.  Navigate to the _Geo-Objects and Hierarchies_ page from the sidebar.

    <figure><img src="../../../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
2.  Click the three dot menu option button to open the options for a hierarchy. Select the _Delete option_.

    <figure><img src="../../../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure>
3.  A message window will appear confirming if you want to delete the hierarchy. Click the _Delete_ button.
