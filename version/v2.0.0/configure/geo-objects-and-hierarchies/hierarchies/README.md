# Hierarchies

A **hierarchy** defines how Geo-Object Types relate to each other as parents and children. For example, an administrative hierarchy could go from Country to Province to District, and a health facility hierarchy could place Health Posts under Health Centres.

Each Geo-Object is linked to its parent Geo-Objects through the hierarchies its Geo-Object Type belongs to. A Geo-Object Type can be part of several hierarchies, and a hierarchy can inherit the upper levels of another hierarchy.
