# Deleting a Geo-Object Type

{% hint style="info" %}
Registry Administrators can delete the Geo-Object Types under the curation mandate of their organization
{% endhint %}

{% hint style="warning" %}
A Geo-Object Type can't be deleted while it's part of a hierarchy. [Remove it from every hierarchy](../hierarchies/manage-the-content-of-the-hierarchy.md) first.

Lists and spatial data for the type don't need to be deleted first. They're marked as invalid when the type is deleted.
{% endhint %}

1. Navigate to the **Geo-Objects and Hierarchies** page from the sidebar.

   <figure><img src="../../../../../.gitbook/assets/image (84).png" alt=""><figcaption></figcaption></figure>
2. Click the three-dot menu next to the Geo-Object Type and select **Delete**.

   <figure><img src="../../../../../.gitbook/assets/image (82).png" alt=""><figcaption></figcaption></figure>
3. A message asks you to confirm that you want to delete the Geo-Object Type. Click **Delete**.
