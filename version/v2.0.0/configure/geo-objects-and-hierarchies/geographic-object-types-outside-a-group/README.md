# Geo-Object Types

A **Geo-Object Type** defines a kind of geographic object, such as a province, a district or a health facility. It sets the geometry that its Geo-Objects have (point, line, polygon or mixed) and the attributes stored for each one. Each Geo-Object Type is managed by one organization.
