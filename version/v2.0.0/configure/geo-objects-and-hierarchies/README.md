# Geo-Objects and Hierarchies

The **Geo-Objects and Hierarchies** page is where you define the structure of your geographic data:

* [**Geo-Object Types**](geographic-object-types-outside-a-group/README.md) define kinds of geographic objects, such as provinces or health facilities, with their geometry type and attributes.
* [**Groups**](geo-object-type-groups/README.md) collect related Geo-Object Types that share a geometry type and attributes.
* [**Hierarchies**](hierarchies/README.md) define how Geo-Object Types relate to each other as parents and children.

At the top of the page's list, choose **Geo-Object Types**, **Hierarchies** or **Directed Acyclic Graph Types**. Items are listed under the organization that manages them, and you can find one with **Search All**. Click an item to view it.

{% hint style="info" %}
Registry Administrators can add, edit and delete Geo-Object Types, groups and hierarchies for their own organization. Other users can view them.
{% endhint %}

Once your Geo-Object Types are set up, load Geo-Objects into them with [Import Geospatial Data](../../curate/import-geospatial-data/README.md).
