# Adding a Business Type

{% hint style="info" %}
Registry Administrators can manage the Business Types of their organization.
{% endhint %}

1.  Navigate to the **Business Types** page from the sidebar and make sure **Business Types** is selected at the top of the list.

    <figure><img src="../../../../.gitbook/assets/image (98).png" alt=""><figcaption></figcaption></figure>
2.  Click **Add** under your organization.
3.  Fill out the form:

    <figure><img src="../../../../.gitbook/assets/image (96).png" alt=""><figcaption></figcaption></figure>

    | Field | Description | Required |
    | ----- | ----------- | -------- |
    | Code | The unique human-readable identifier of the Business Type. It can't be changed later. | Required |
    | Label (Default Locale) | The display label for the Business Type. It's used when the default locale is selected in the language toggle, or when another language is selected but has no label. | Required |
    | Label (other installed locales) | A display label for each other locale installed in the system. | |
    | Description | A description of the Business Type, with one field per installed locale. | |
    | Organization | The organization that manages the Business Type. It's filled in with the organization you clicked **Add** under, and can't be changed. | |
4.  Click **Ok**. The new Business Type opens, and you can add its attributes and choose its label attribute. See [managing-attributes-of-a-business-type.md](managing-attributes-of-a-business-type.md "mention") and [editing-a-business-type.md](editing-a-business-type.md "mention").
