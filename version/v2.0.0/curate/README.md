# Curate

The **Curate** part of the sidebar is where you load data into Geoprism Registry and keep it accurate over time.

## Loading data

| Page | What it's for |
| ---- | ------------- |
| [Import Geospatial Data](import-geospatial-data/README.md) | Load Geo-Objects from a spreadsheet or shapefile. |
| [Import Business Data](import-business-data.md) | Load business objects and Concepts from a spreadsheet. |
| [Import Edge Data](import-edge-data.md) | Load relationships between existing objects from a JSON file. |
| [Scheduled Jobs](scheduled-jobs/README.md) | Follow imports as they run, and fix any problems they find. |
| [Rollback Data](rollback-data.md) | Undo an import by returning the registry to its state before it. |

## Maintaining data

| Page | What it's for |
| ---- | ------------- |
| [Change Requests](change-requests/README.md) | Suggest changes to Geo-Objects, and review changes suggested by others. |
| [Historical Events](historical-events/README.md) | Record events such as mergers, splits and reassignments that change Geo-Objects over time. |

You can also edit Geo-Objects one at a time in the [Explorer](../explore/explorer/README.md), and check lists for problems with [Run Curation](../explore/lists-and-spatial-data/curating-lists-and-spatial-data.md).
