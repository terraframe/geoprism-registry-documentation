# Explore

The **Explore** part of the sidebar is where you view your data and publish it for others.

| Page | What it's for |
| ---- | ------------- |
| [Explorer](explorer/README.md) | View Geo-Objects on a map, see their history and relationships, and edit them. |
| [Lists and Spatial Data](lists-and-spatial-data/README.md) | Publish the Geo-Objects of a type as a list and map layer for a date or period, and export them as a spreadsheet or shapefile. |
| [Spatial Knowledge Graphs (SKG)](spatial-knowledge-graphs-skg/README.md) | Publish versioned graphs of your data for external systems. |
| [Labeled Property Graphs](labeled-property-graphs.md) | Download a simple RDF graph of your data. This is an older way to share data; for new integrations, use Spatial Knowledge Graphs. |
