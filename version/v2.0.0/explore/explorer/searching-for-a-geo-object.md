# Searching for a Geo-Object

1.  In the search bar, optionally enter a date, then type a name or code in **Search for Geo-Objects to edit** and click the search button.
2.  The results are listed, and shown on the map as a **Search Results** layer. Click a result to open it. See [viewing-a-geo-object.md](viewing-a-geo-object.md "mention").
